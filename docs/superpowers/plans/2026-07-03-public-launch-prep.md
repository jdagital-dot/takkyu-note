# 一般公開準備 実装プラン

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 機能はすべて無料のまま、不特定多数のユーザーが安心して登録・利用できる状態にして一般公開する。

**Architecture:** 既存の単一HTML + js/ モジュール構成を維持。分析ロジックは index.html 内の renderMatches 系に追加（将来のモジュール分割は別途）。法的ページは静的HTML 2枚を追加。

**Tech Stack:** 既存構成（Vanilla JS / Supabase / Vercel）

**方針転換の経緯:** J.STYLE 内での試用配布は行わず（事情により不可）、一般公開でユーザーを獲得する。フリーミアム制限は Phase 3（課金導入）まで作らない — 今は「全機能無料」を拡散の武器にする。

**運営者名義:** サービス名義「卓球記録ノート運営事務局」、連絡先 joetsu.pingpong@gmail.com

## Task 1: 分析画面の実データ連動 ⭐最優先

今の分析タブは戦型別・年齢別・傾向タグが**固定ダミー値**。一般公開して最初に
見られる画面が嘘の数字だと信頼を失うため、公開前に必ず実データ化する。

**Files:**
- Modify: `index.html`（分析画面のHTML・renderMatches に集計処理追加）

- [ ] 戦型別勝率: 現在選手の matches を `type` ごとに集計し、勝率バーを動的生成
      （2試合以上ある戦型のみ表示。0件時は「まだデータがありません」）
- [ ] 年齢カテゴリ別勝率: getAgeCategory（年下/同世代/年上）ごとに勝率を集計
- [ ] 傾向・強み・課題: 勝ち試合の頻出タグ上位2つ→「強み」、負け試合の頻出
      タグ上位2つ→「課題」（各タグ2回以上出現時のみ。なければ空状態メッセージ）
- [ ] 試合0件時: 分析画面全体に「試合を記録すると分析が表示されます」の空状態
- [ ] E2E: 分析画面に実データが反映されるテストを追加

## Task 2: プライバシーポリシー・利用規約

**Files:**
- Create: `privacy.html`（プライバシーポリシー）
- Create: `terms.html`（利用規約）
- Modify: `index.html`（登録ボタン下に同意文言）、`sw.js`（キャッシュ対象に追加）

- [ ] privacy.html: 収集情報（メール・選手名・学年・試合記録・対戦相手名）、
      利用目的、保管先（Supabase/東京リージョン）、第三者提供なし、
      削除依頼方法（メール連絡）、連絡先、改定について
- [ ] terms.html: サービス内容、無料提供・保証なし、禁止事項、データの
      バックアップ免責、サービス変更・終了、準拠法
- [ ] 登録フォーム下に「登録すると利用規約・プライバシーポリシーに同意した
      ものとみなされます」＋各ページへのリンク（みなし同意方式）
- [ ] ログイン画面フッターにも両ページへのリンク
