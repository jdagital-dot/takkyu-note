## 2. コードレビュー結果（2026-07-03 実施・修正済み）

### 修正した問題

1. **致命的: 試合の編集・削除が動かない** — 試合詳細モーダルの
   `onclick="confirmDeleteMatch(${m.id})"` が UUID を引用符なしで埋め込んでいて
   クリック時に構文エラー。`'${m.id}'` に修正。
2. **sw.js のキャッシュ戦略が破綻していた** —
   - index.html がキャッシュ優先 → デプロイが反映されず CACHE バージョンを
     手動で v25 までバンプし続けていた。**同一オリジンはネットワーク優先**に変更し、
     以後の手動バンプを不要にした。
   - js/ モジュールと esm.sh（supabase-js CDN）がキャッシュされておらず、
     オフラインでは実は起動不能だった。precache + ランタイムキャッシュで解消。
3. **autoRefreshToken: false によるトークン失効** — 大会で開きっぱなしにすると
   1時間で保存が失敗し始める。ハングの真因（navigator.locks）は noOpLock で
   対策済みのため、自動更新を再有効化。
4. 軽微: 年表示ハードコード、getAgeCategory の14歳固定（現在選手の学年ベースに）、
   updateMatch の date が JSON.stringify の undefined 削除に暗黙依存、
   main.js の Supabase ref 重複とログアウト処理の重複。

### 未修正・今後の必須課題

- **XSS（Phase 2 開始前に必須）**: 選手名・相手名・チーム名・メモを innerHTML に
  エスケープなしで挿入している。Phase 1 では自分のデータしか表示しないため実害は
  ないが、**クラブ共有（他人のデータ表示）を実装する前に必ず escapeHtml を導入**すること。
- **index.html が1900行超** — 記録画面・分析画面・アドレス帳のロジックを
  js/ モジュールへ段階的に切り出したい（機能追加のタイミングで）。
- 分析画面の戦型別・年齢別・タグ集計がまだ静的HTML（実データ非連動）。

## 3. 運用上の重大発見: Supabase 無料プランの自動一時停止

**2026-07-03 時点で Supabase プロジェクトが pause 状態**（DNS が NXDOMAIN）。
無料プランは約1週間アクティビティがないとプロジェクトが自動停止する。

- **復元**: Dashboard → プロジェクト → 「Restore」ボタン（数分で復旧）
- **復元後の注意**: pause 前からブラウザに残っていた古いセッションはトークン
  更新が固まり、保存操作がハングすることがある（2026-07-03 実機で確認）。
  症状が出たら**ログアウト→再ログイン**で解消。全リクエストに15秒タイム
  アウトを入れたので、以後は永久に固まらずエラートーストが出る
- **恒久対策（本番運用前に必須、いずれか）**:
  1. GitHub Actions で毎日1回 Supabase に軽いクエリを打つ keep-alive を設定（無料）
  2. Pro プラン（$25/月）に上げる（pause なし・バックアップ付き）
- J.STYLE で実運用を始めるなら、ユーザーが毎日使うので自然に解決する可能性も
  あるが、夏休み等の長期休みで止まるリスクは残る → keep-alive 推奨
