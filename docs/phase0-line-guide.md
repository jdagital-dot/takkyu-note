# Phase 0 試用配布キット（LINE用）

対象: J.STYLE の試用協力メンバー3〜5家庭
期間: 配布から2週間
目的: 実戦での使い勝手検証・フィードバック回収

---

## LINE 配布文（コピペ用）

```
【お願い】卓球の試合記録アプリを試してほしいです🏓

J.STYLEの活動をより良くするために、試合の記録・分析ができる
スマホアプリを作りました。2週間ほど試しに使ってみて、
感想を聞かせてもらえませんか？（無料です）

▼アプリはこちら
https://pingpong-app-one.vercel.app

▼はじめかた（3分で終わります）
① 上のリンクをスマホで開く
② 「Google で続ける」または メールアドレスで登録
③ お子さんの名前と学年を登録
④ 【重要】ホーム画面に追加するとアプリのように使えます
   ・iPhone: 共有ボタン（□↑）→「ホーム画面に追加」
   ・Android: メニュー（⋮）→「アプリをインストール」

▼使い方
・試合が終わったら「＋」ボタンから記録
・相手の名前・戦型・スコアを入力するだけ
・「分析」タブで勝率などが自動集計されます
・兄弟がいる場合は1つのアカウントに選手を追加できます
（画面右上の名前から切替）

わからないことがあれば気軽に聞いてください！
2週間後に感想を聞かせてもらえるとうれしいです。
```

## 配布時のチェックリスト

- [ ] 試用メンバーを3〜5家庭選ぶ（練習熱心で協力的な家庭）
- [ ] LINEで上記文面＋QRコード画像（qr-code.png）を送る
- [ ] 登録でつまずいた人がいないか2〜3日後に声かけ
- [ ] 大会・練習試合の後に「記録してみた？」とリマインド

## 2週間後に聞くこと

1. 何試合記録できたか（続いたか）
2. 入力でめんどうだった箇所
3. 欲しい機能・いらない機能
4. 保護者と子ども、どちらが入力したか
5. 月300〜500円なら使い続けたいか（率直に）

## 既知の注意事項（質問が来たら）

- メール登録の確認メールが迷惑メールに入ることがある
- オフライン（体育館の圏外）では保存できない → 電波のある場所で入力してもらう
- 機種変更してもログインすればデータは引き継がれる
