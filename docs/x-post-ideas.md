# X投稿ネタストック（2026-07-07作成）

週2〜3回ペースで約1ヶ月分。使ったらチェックを付ける。
基本は「プロフィールのリンクから」誘導（外部リンク直貼りは伸びにくい）。

---

## ① 共感あるある

- [ ] 使用済み

```
対戦表を見て「あ、この名前前も当たった気がする」→どんな卓球だったか思い出せないまま試合開始。
1回記録しておくだけで、次からは戦型も前回のスコアも一瞬で振り返れます🏓
#卓球
```

## ② Tips（負け試合の価値）

- [ ] 使用済み

```
試合の記録は「負けた試合」ほど価値があります。
負け試合に付けたタグ（レシーブ・ラリー・メンタル…）が溜まると、自分の課題が数字で見えてくる。感覚で「なんとなく苦手」より、データで「レシーブで負けてる」の方が練習が変わります🏓
#卓球
```

## ⑥ Tips（タグ活用）

- [ ] 使用済み

```
試合記録にタグを付けるコツ：
勝った試合→「何が効いたか」（サーブ・3球目・コース）
負けた試合→「何をやられたか」（レシーブ・ラリー・回転読み）
溜まってくると、勝ちパターンと課題が自動で「強み/課題」に表示されます🏓
#卓球
```
