# 手動テストチェックリスト

リリース前・大きな変更後にスマホ実機で一通り確認するためのリスト。
所要時間: 約15〜20分

## 0. 準備

- [ ] スマホで https://pingpong-app-one.vercel.app を開く
- [ ] **一度アプリ（タブ）を完全に閉じて開き直す**（Service Worker の更新を確実に反映させるため）
- [ ] PWA（ホーム画面追加済み）の場合も一度スワイプで終了して起動し直す

## 1. 認証

- [ ] ログアウト状態でログイン画面が表示される
- [ ] メール＋パスワードでログインできる
- [ ] 間違ったパスワードで「メールまたはパスワードが間違っています」と表示される
- [ ] （新規メールがあれば）新規登録 → **確認メールが数分以内に届く**（Gmail SMTP確認）→ リンクで認証完了
- [ ] Google でログインできる
- [ ] ログアウト → ログイン画面に戻る → 再ログインできる

## 2. 選手管理

- [ ] 新規アカウントの場合、オンボーディング（選手登録）が表示される
- [ ] 選手を追加すると右上に切替UIが出る（2人以上のとき）
- [ ] 切替で選手ごとの試合一覧が切り替わる
- [ ] ✎ から選手の学年・利き手・戦型を編集できる
- [ ] 選手を削除できる（1人になると切替UIが消える）

## 3. 試合記録 ⭐重点（直近で修正した箇所）

- [ ] ＋から試合を記録できる（相手名・学年・戦型・スコア・タグ・メモ）
- [ ] スコアは片方入力でもう片方が自動計算される
- [ ] 記録後ホームにカードが表示され、勝率・勝敗数が更新される
- [ ] カードをタップ → 詳細モーダルが開く
- [ ] **「編集する」→ フォームに既存値が入った状態で開く → 変更 → 更新できる** ⭐
- [ ] **「削除」→ 確認ポップアップ → 削除できる** ⭐
- [ ] リロードしても記録が残っている

## 4. アドレス帳

- [ ] 未登録の相手で試合を記録すると「アドレス帳に追加しますか？」が出る
- [ ] 登録済みの相手（名前完全一致 or 部分一致＋チーム/学年一致）では出ない
- [ ] 🔍（虫眼鏡）から選手を選ぶと情報が自動入力され、ポップアップが閉じる
- [ ] アドレス帳から選手を追加・削除できる

## 5. 同期・複数端末

- [ ] 別の端末（またはPCブラウザ）で同じアカウントにログイン → 同じ試合が見える
- [ ] 片方で記録 → もう片方でリロード → 反映される

## 6. PWA・オフライン

- [ ] ホーム画面に追加できる（アイコン「卓」）
- [ ] ホーム画面から起動するとブラウザUIなしで表示される
- [ ] 機内モードで起動 → キャッシュ済みの試合一覧が表示される（閲覧できればOK。保存はオンライン必須）
- [ ] 機内モード解除後、正常に保存できる

## 7. 長時間セッション（時間があれば）

- [ ] アプリを開いたまま1時間以上放置 → 試合を記録 → 保存できる（トークン自動更新の確認）
